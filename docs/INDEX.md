# RobotWorld 文档中心

本目录是 RobotWorld 的正式文档入口，按使用目的分为“开发与维护”和“用户与集成手册”两大类。开发文档同时服务于人类开发者和自动化开发代理，统一遵守同一套架构、编码和交付约定。

## 文档分类

### 开发与维护

[开发与维护](develop/INDEX.md) 面向参与项目建设的所有开发者，覆盖：

- 软件架构、领域模型和编码规范；
- 产品需求（PRD）、技术设计和开发计划；
- 路线图、里程碑和活跃开发队列；
- 开发验证、验收记录和完成归档。

开发资料的基本流转关系为：

```text
路线图 / 里程碑（ROADMAP） → 产品需求（PRD） → 技术设计 / 开发计划（ARCHITECTURE、design）
→ 活跃队列（BUILD_QUEUE） → 开发与验证 → 验收归档 → 复盘回写
```

### 用户与集成手册

[用户与集成手册](manual/INDEX.md) 面向软件用户、集成商和扩展开发者，覆盖：

- 软件功能和使用说明；
- 工艺流程与后处理器开发；
- 厂商 CAD、设备和外部系统接入；
- 扩展开发、打包和分发说明。
