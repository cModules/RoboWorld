## 2. 技术方案要点

| 决策 | 理由 |
|---|---|
| 右侧用 `QTabWidget` 承载四个面板 | 一次只展开一个 → 天然满足"按需展开、无冗余" |
| 各面板外套 `QScrollArea` | 内容自然高度超过标签页可视高度时会被裁切，本项目已两次踩坑 |
| Dock 图标用 Qt 应用级图标 `QGuiApplication.setWindowIcon` | 用户选择零依赖方案，不引入 pyobjc |
| Dock 名称改用 `.app` bundle | macOS Dock 名称取自 `CFBundleName`，Qt 层面无法覆盖进程名 |
| 提供 `RobotWorld-Dev.app` 启动器 | 既让 Dock 名称正确，又保留"改代码免打包"的开发体验 |

## 4. 验收方式

界面改动**必须用无头探针实测**，不靠阅读代码判断（脚本：
`~/.codebuddy/skills/evidence-driven-fix/scripts/qt_widget_probe.py`）。

| 验证项 | 实测结果 |
|---|---|
| 右侧标签构成 | `['属性', '动作与从属', '代码预览', '导出打包']` ✅ |
| 各页自然高度 ≤ 可用高度 728 | 属性 526 ／ 动作与从属 360 ／ 代码预览 264 ／ 导出打包 360 ✅ |
| 位置面板项数 | 6（X/Y/Z + 绕X/绕Y/绕Z）✅ |
| 轴声明与参数面板过滤 | 双轴(rot,tilt)／单轴(rot)／夹爪(jaw,mm)／台钳(jaw,mm)／压板无轴 ✅ |
| 回转轴几何响应 | `rot_deg` 0°→90°，旋转矩阵最大差异 1.0（非 0，未被过滤）✅ |
| 轴滑块写回 | 拖到 90° → `obj.params["rot_deg"] = 90.0` ✅ |
| 应用级图标已设置 | `QGuiApplication.windowIcon()` 非空 ✅ |
| `.app` 的 Dock 名称 | `CFBundleName = RobotWorld` ✅ |
| 开发启动器 Dock 名称 | `LSDisplayName = RobotWorld-Dev` ✅ |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 面板内容超出可视高度被裁切 | 统一套 `QScrollArea`，每次改动后探针复测 |
| `cnb` 推送含二进制时连接中断 | 用 `git -c http.postBuffer=524288000 push`（单次生效，不改配置） |
| `logo.icns` 由 `logo.png` 派生，可能过期 | 生成命令已写入 `rw.spec` 头部注释 |
