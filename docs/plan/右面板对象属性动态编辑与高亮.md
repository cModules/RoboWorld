## 用户需求

在保持现有选中交互（视口右键 / Control+左键 / 场景树点选，左键仍只旋转视角）的前提下，新增「对象属性动态编辑」与「选中高亮」两项能力：

## 核心功能

- 选中对象后，右侧 `DevicePropertyPanel` 随选中对象动态切换：
- 选中机器人（默认 / 未选中场景对象）→ 显示「机器人信息」+「关节控制」。
- 选中场景对象（工作台、控制柜等）→ 切换显示该对象的「对象属性」：组件类型、位姿（X / Y / Z / 绕Z°）、以及由组件 `ParamSpec` 自动生成的参数控件（台面长/宽等），数值可编辑并实时回写场景。
- 选中对象在 3D 视口中高亮显示（亮黄描边）；取消选中或删除/清空对象后高亮消失；干涉检查命中对象保持红色线框高亮。
- 视口选中与场景树点选双向同步到右面板。

## 技术栈

- 沿用现有栈：PySide6（Qt Widgets）+ PyQt/PySide OpenGL 视口（`rw.py` 的 `GLWidget`）。
- 复用现有模式：场景对象属性由 `orolp.world.components.ParamSpec` 自动生成控件（参考 `panel.py` 208-223）；位姿编辑直接写 `scene.objects[name].pose` 并触发 `sceneChanged`（参考 `panel.py` 287-303）；几何经 `scene.object_parts()` 按 `obj.params` 实时重建，无需额外缓存刷新。

## 实现方案

1. **选中高亮可见性修正（根因修复）**

- `_draw_part(part, tf_parent=None, force_color=None)`：新增 `force_color` 形参，给定时跳过 `gl.glColor3f(*part.color)`，改用指定色。
- `_highlight_object(self, name, color=None)`：选中默认亮黄 `(1.0, 0.85, 0.0)`，干涉红 `(1.0, 0.25, 0.15)`（调用处传入）；绘制时 `glDisable(GL_LIGHTING)`、`glDisable(GL_DEPTH_TEST)`，线框模式、线宽 2.5，调用 `_draw_part(part, force_color=color)`，结束恢复。
- 调用点：`paintGL` 738-739 改为 `self._highlight_object(self.selected_object, (1.0, 0.85, 0.0))`；767 干涉改为 `self._highlight_object(hit.obj_b, (1.0, 0.25, 0.15))`。
- 说明：当前高亮「不可见」并非缺失，而是 `_draw_part` 内部用 `part.color` 覆盖了描边色；只改颜色传递路径即可，不影响其它绘制。

2. **右面板动态属性（DevicePropertyPanel）**

- 新增 `set_scene(scene)` 保存场景引用；新增信号 `objectChanged = Signal()`。
- `_setup_ui` 增加默认隐藏的 `object_group`：名称、类型标签 + 位姿四联 `DoubleSpinBox`（x/y/z/rz）+ 参数容器 `param_form`。
- 新增 `set_object(name)`：
    - `name` 为 `None` 或不在 `scene.objects` → 隐藏 `object_group`，显示「机器人信息」+「关节控制」。
    - 场景对象 → 隐藏机器人信息/关节分组，显示 `object_group`；按 `COMPONENTS[component_id].params`（`ParamSpec` 的 label/范围/步长/单位）自动生成参数字段并回填当前值；回填位姿。
- 位姿 / 参数 `valueChanged` → 写回 `scene.objects[name].pose` / `.params[...]` → `emit objectChanged()`。

3. **信号接线（MainWindow.setup_ui）**

- `self.gl_widget.objectSelected.connect(self.property_panel.set_object)`（视口选中更新右面板）。
- `ScenePanel` 新增 `objectSelected = Signal(str)`；`MainWindow` 将其 `connect(self.property_panel.set_object)`（场景树点选同步）。
- `self.property_panel.objectChanged.connect(self.gl_widget.update)`（编辑后重绘视口）。

4. **依赖与降级**

- `_HAS_WORLD` 分支内 `from orolp.world.components import COMPONENTS, ParamSpec`；`_HAS_WORLD` 为假时 `set_object` 退化为仅显示机器人信息。

## 性能与可靠性

- 控件重建仅在 `set_object` 切换对象时发生（非每帧），右键拖动时不重建面板，避免开销。
- 几何重建沿用例行的 `object_parts()` 惰性计算，编辑参数仅触发一次 `gl_widget.update()`。
- 高亮为线框叠加、关闭深度测试，开销极低；不引入额外帧缓冲。
